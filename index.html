Who we are

A small design & development studio focused on delivering fast, accessible, and delightful web experiences. This template demonstrates core patterns for building modern static websites without toolchains.

How to use

  1. Download this file and rename to index.html.
  2. Edit text, replace images, and point forms to your backend.
  3. Host anywhere: GitHub Pages, Netlify, Vercel or a traditional web host.
